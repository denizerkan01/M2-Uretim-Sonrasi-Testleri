M2GR Üretim Testi web arayüzü

Başlatma:
1. Cihazı PC'ye bağlayın ve ArView'i kapatın.
2. "Start M2GR GUI.bat" dosyasına çift tıklayın.
3. Tarayıcıda açılan panelde cihazın etiketindeki PN ve SN'yi girip Başlat'a basın.

Panel yerel Python backend'ini 127.0.0.1:8782 adresinde açar ve sekiz aktif M2GR testinin durumunu, Geçti/Kaldı sonucunu ve Python kayıtlarını gösterir. Testleri çalıştırmak için ArView ve proje bağımlılıklarının bu PC'de kurulu olması gerekir.

Başlatıcı Python 3.14 pythonw.exe konumunu dener; yoksa PATH içindeki pythonw komutunu kullanır.
